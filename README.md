# Christmas Terminal Animation

Animação natalina executada no terminal, com árvore colorida, enfeites aleatórios e texto sincronizado em etapas.

## Tecnologias

- Python 3
- Colorama
- sequências ANSI para controle do terminal

## Executando

~~~bash
git clone https://github.com/it0l/christmas.git
cd christmas
pip install -r requirements.txt
python natal.py
~~~

O projeto foi desenvolvido com foco no terminal do Windows. Em outros sistemas, alguns recursos de abertura de janela podem se comportar de maneira diferente.
